# Planning La Bocca

Planning des livraisons de béton de la centrale de Cannes La Bocca : démonstration.

La page est chiffrée : elle ne s'ouvre qu'avec le mot de passe communiqué par le centraliste.
Toutes les données de la démo (clients, chantiers, adresses, téléphones) sont fictives.

- Lien : https://sijocha.github.io/planning-la-bocca/
- Code d'accès au planning (après le mot de passe) : demandé à l'ouverture.
